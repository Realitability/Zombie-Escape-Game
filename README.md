# Zombie Escape Game
This is my first attempt at making a game and probably is not finished by the time you are reading this.
GuiTK is required to play.

## How to run

### Setup

Firstly, you need to install the requirements:
```
pip install -r requirements.txt
```

### Running

Then, change into the game directory:
```
cd ZombieEscape2
```
Then, run `main.py` with python
```
python main.py
```
